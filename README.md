# AI 시대, 교사의 시간

인터랙티브 디자인 수업 작품 · HTML / CSS / JavaScript 웹 인터랙티브 (Scene1 ~ Scene12, A엔딩)

---

## 1. 내 컴퓨터에서 열어 보기

`index.html`을 더블클릭하면 브라우저(Chrome 추천)에서 열려요.
글꼴(Pretendard)은 인터넷에서 불러오니 인터넷이 연결되어 있어야 해요.

**확인용 바로가기**: 주소창 끝에 `?scene=번호`를 붙이면 그 장면부터 시작해요.
예) `index.html?scene=5` → 기사 검색 장면부터 (Scene3은 1번 학생으로 시작)

## 2. GitHub에 올려서 웹에서 보기 (GitHub Pages)

1. https://github.com 에 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름을 정하고(예: `ai-teacher-time`) **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요
4. 이 폴더 **안에 있는 것 전부**(`index.html`, `style.css`, `README.md`, `js`, `data`, `assets`)를 끌어다 놓아요
   - 폴더 자체가 아니라 **폴더 안의 내용물**을 끌어다 놓아야 `index.html`이 맨 위에 와요
   - 파일이 98개라서 한 번에 올라가요 (GitHub 웹 업로드는 한 번에 100개까지)
5. 아래 **Commit changes** 클릭
6. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
7. **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**
8. 1~2분 기다리면 같은 화면 위쪽에 주소가 나와요: `https://내아이디.github.io/저장소이름/`

나중에 고친 파일만 다시 올릴 때도 3~5번처럼 끌어다 놓으면 같은 이름 파일이 바뀌어요.

## 3. 폴더 구성

```
index.html        무대(1456×816)와 장면 12개의 자리
style.css         모든 모양 (맨 위 :root에 색 이름표)
js/core.js        공통 도구: 화면 맞추기, 클릭 기다리기, 커튼·페이드, 걷는 캐릭터, 말풍선, 종료 조건
js/scenes.js      장면 1~12 (장면마다 함수 하나)
data/cards.js     학생 20명 카드 자료 (cards_data.json 그대로 옮김)
data/interview.js 면담 질문·답 (docs/03 그대로), 걷기 수치 표
data/articles.js  Scene5 가상 기사 3편 (docs/04 그대로)
assets/           그림·영상 (웹용으로 줄이고 WebP로 바꾼 것)
```

- 걷기 그림은 프레임 1~N과 멈춘 모습(stand)을 가로로 이어 붙인 한 장(`assets/chars/walk/*.webp`)이에요.
- 카드 좌표는 원본 1200×560 기준 그대로예요. 그림만 가볍게 줄였어요.

## 4. 장면 흐름

| 장면 | 내용 | 조작 |
|---|---|---|
| 1 | 검은 화면 글귀 2개 | 자동 |
| 2 | 학생 카드 20장 (슬롯머신 → 선 → 도장 → 이름) | 카드 클릭 |
| 3 | 면담 (질문·답 3번) → 면담한 카드가 가운데로 와서 뒤집혀요 | 클릭 / 스페이스 |
| 4 | 생각 구름 "검색해볼까?" | 클릭 |
| 5 | 모니터 검색 → 기사 3편(선택) → ✕ → 메신저 | 기사·✕ 클릭 |
| 6·8 | 복도 걷기 | 자동 |
| 7·9 | 영상 + 말풍선 | 클릭 |
| 10 | 밤 → 아침, 잠든 교수, 옆 연구실 교수, 학생 5명 | 자동 |
| 11 | 시간빈곤 설명 7화면 (그래프 모션) | 클릭 |
| 12 | A엔딩 | 처음부터 다시 |

**면담 종료 조건**: 4유형(고활용·검증결핍·중저활용·검증우세) 모두 + 유료 2명 이상 + 무료 2명 이상 + 미사용 1명 이상.
조건을 채우면 면담이 끝날 때마다 "면담을 종료할까?"를 물어요. 10번째 면담부터는 아직 못 채운 조건에 맞는 학생 카드가 빛나며 "똑똑, 교수님!" 하고 먼저 찾아와요.
